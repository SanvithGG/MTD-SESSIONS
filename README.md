# MTD Sessions

MTD Sessions is a learning archive of Java, Spring Boot, and React practice projects organized by development session date.

This repository is best used as a record of training work and topic progression. For a polished portfolio project, see `smart-grocery`.

## What This Repository Shows

- Spring Boot REST API practice
- Java backend project structure
- JPA and database integration exercises
- React and Vite frontend practice
- Small full-stack examples connecting frontend and backend work
- Authentication, validation, billing, school management, and todo app exercises

## Running Backend Projects

Most Java projects can be run from their own folder:

```bash
cd path/to/project
./mvnw spring-boot:run
```

On Windows, use:

```powershell
.\mvnw.cmd spring-boot:run
```

## Running Frontend Projects

Most React projects can be run from their own folder:

```bash
cd path/to/project
npm install
npm run dev
```
